Резервная копия, которая остаётся зашифрованной.

Devices backup — личный инструмент владельца облачного хранилища для сохранения и проверки резервных копий базы KeePassXC.

Для чего нужен доступ к Google Drive

Приложение загружает зашифрованный файл базы, скачивает копию для проверки целостности и обновляет рабочую резервную копию. Пароль базы для этих операций не нужен.

Используется разрешение drive.file: доступ к созданным приложением файлам либо к файлам, которые пользователь явно предоставил приложению. Доступ ко всем файлам Google Диска не запрашивается.

Как устроено резервирование

  1. Пользователь сохраняет базу локально в KeePassXC.
  2. Средства автоматизации копируют уже зашифрованный файл в выбранное хранилище.
  3. Загруженный файл скачивается обратно, а его контрольная сумма сравнивается с локальной.

При настройке владельцем дополнительная зашифрованная копия может храниться в Яндекс.Диске. Это отдельное подключение.

Приложение используется лично владельцем. Здесь нет регистрации, веб-формы входа в базу или приёма паролей. Резервные копии не размещаются на этом сайте.
