# Devices backup — служебный сайт

Публичные страницы личного инструмента резервирования зашифрованной базы KeePassXC.

- `index.html` — назначение приложения и запрашиваемый доступ Google Drive.
- `privacy/index.html` — политика конфиденциальности.
- `style.css` — общий стиль, без внешних библиотек и скриптов.

Сайт публикуется через GitHub Pages. Здесь нет баз KeePassXC, ключей,
OAuth-реквизитов, резервных копий устройств или описания домашней сети.
