Devices backup

Политика конфиденциальности

Действующая редакция: 17 ноября 2026 года. Эта политика описывает личный инструмент резервирования Devices backup и его служебные информационные страницы.

Назначение и данные

Приложение предназначено для резервирования зашифрованной базы KeePassXC владельца облачного хранилища. Через Google Drive API оно получает доступ к файлам, созданным приложением или явно предоставленным ему пользователем, в пределах разрешения drive.file.

Для выполнения операций используются содержимое зашифрованного файла и технические метаданные: имя и идентификатор файла, размер, время изменения и контрольные суммы. Они нужны для загрузки, проверки, поиска и обновления резервной копии.

Использование и передача

Данные Google Drive используются только для указанных операций резервирования. Они не продаются, не используются для рекламы или обучения моделей машинного обучения.

База шифруется KeePassXC до загрузки. Если владелец включил дополнительный резерв в Яндекс.Диске, туда отдельно отправляется зашифрованная копия. Средства автоматизации, выбранные владельцем, могут обрабатывать технические статусы и метаданные операций; их использование регулируется также политиками соответствующих провайдеров.

Секреты и защита

Мастер-пароль вводится владельцем локально для работы с KeePassXC. Он не нужен для копирования зашифрованного файла и не должен передаваться в облачные хранилища, на этот сайт или в журналы операций. OAuth-реквизиты хранятся локально с ограниченными правами и могут резервироваться внутри зашифрованной базы.

Расшифрованное содержимое базы и значения секретов не включаются в отчёты автоматизации. Доступ к хранилищам осуществляется через HTTPS. Возможность восстановления зависит также от сохранности пароля и дополнительных факторов защиты, выбранных владельцем.

Хранение и удаление

Копии находятся на устройстве владельца и в подключённых им облачных хранилищах. Владелец управляет файлами, сроками хранения и удалением. Корзина и версии файлов могут сохраняться провайдером согласно его настройкам и условиям. Этот сайт не хранит резервные копии пользователей.

Управление доступом

Разрешение приложению можно отозвать в настройках подключений аккаунта Google. Отзыв не удаляет уже созданные резервные файлы: ими владелец управляет в самом хранилище. Подключение Яндекс.Диска отзывается отдельно в настройках Яндекс ID.

Служебный сайт и связь

На этих страницах нет регистрации, форм приёма паролей, собственной рекламной аналитики или платёжных функций. Служебный сайт размещён на GitHub Pages. GitHub записывает IP-адреса посетителей для обеспечения безопасности; обработка этих технических данных описана в политике конфиденциальности GitHub.

По вопросам работы приложения используйте адрес поддержки, указанный на экране согласия Google OAuth для Devices backup.

Соответствие правилам Google

Использование и передача данных, полученных через Google API, ограничиваются назначением приложения и требованиями Google API Services User Data Policy, включая применимые требования Limited Use. При изменении способов обработки эта политика должна быть обновлена до использования данных для новых целей.
